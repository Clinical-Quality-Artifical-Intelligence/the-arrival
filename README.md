# The Arrival — The Future of Nursing Citizen Development

Interactive WebGL 2.0 film & keynote presentation by **Lincoln Gombedza**, Founder of Nursing Citizen Development.

- **Live URL**: https://future.nursingcitizendevelopment.com
- **Main Portal**: https://nursingcitizendevelopment.com

## Controls
- **Autoplay**: Plays automatically on load (`P` or `▶ AUTO` button to pause/resume)
- **Sound**: Procedural generative Web Audio soundtrack (`M` or speaker button to mute/unmute)
- **Navigation**: `→` / `Space` / Click to advance, `←` / Right-click to step back
- **Speaker Notes**: `N`
- **Full Screen**: `F`
- **Black Screen**: `.` or `B`
